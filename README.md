# Expense Tracker

A modern static expense tracker web app built with HTML, CSS, and JavaScript.

## Features
- Add income and expense transactions
- Select category or enter a custom category
- Record transaction date and recurrence
- Edit and delete individual entries
- Filter by type, category, date range, and search text
- Summary totals for income, expenses, balance, and transaction count
- Category breakdown and monthly cash flow charts
- Dark mode toggle
- Data saved to browser local storage

## Usage
1. Open `index.html` in your browser.
2. Add a transaction using the form.
3. Use filters to search and review your history.
4. All data is automatically stored locally in your browser.
